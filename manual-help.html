Part 13

Updates, help and troubleshooting

How the app keeps itself up to date, where to see what changed, how to get in touch, and fixes for the things people most often run into. A glossary of the app's terms closes the manual.

Updates

The app updates itself. You don't need to download anything from the website again.

  • It checks for a new version when it opens, and every 2 hours after that while it stays open.
  • When it finds one, it downloads it quietly in the background. You can keep working.
  • Once the download is ready, a message says the new version is ready to install. Click Restart Now to install it straight away; the app closes and reopens on the new version.
  • Click Later to carry on. The update installs the next time you quit the app, and you won't be asked again about that version.

Your work is saved before the app quits, and your data is backed up before an update changes it. Part 11 has the details.

Checking by hand

Choose Check for Updates… from the Setup Sheet Helper menu. If there's nothing new, it says You're up to date. If there is, it downloads and you get the same Restart Now or Later choice. If the check can't go through, usually because you're offline, it says Couldn't check for updates. along with the reason.

Tip

To see which version you have, choose About Setup Sheet Helper from the same menu.

What's New

The first time you open the app after an update, a What's new window lists what changed. It doesn't appear on a fresh install, only after an upgrade.

To read it again any time, choose What's New… from the Setup Sheet Helper menu. It shows every version, newest first, with its date. Click Got it to close it.

Sending feedback

Found a bug, or have an idea? Send it from inside the app:

  1. Open Settings → Feedback

    Press ⌘, and click the Feedback tab.

  2. Choose a type and fill in the form

    Pick Feature Request, Bug Report or Other, then fill in your name, email and message.

  3. Click Send

    You need an internet connection. If sending fails, your message stays in the form so you can try again.

For a bug report, say what you were doing, what you expected, and what happened instead. Your app version helps too. Part 10 describes the form.

Troubleshooting

The toolbar says "Couldn't save — retrying"

Keep working. The app tries again every 10 seconds and saves as soon as it can. Your edits stay on screen in the meantime. The status goes back to Saved once it gets through. If it stays stuck, check that your Mac has free disk space, then send a bug report from Settings → Feedback.

An export says it couldn't reach the Layout window

This happens when the floor plan is open in the pop-out Layout window. To put the room layout in a PDF or spreadsheet, the app asks that window for a picture of the plan. If the window doesn't answer within 3 seconds, the export can't include it.

  • If you exported only the room layout, nothing is saved. The message asks you to bring the Layout window to the front and try again.
  • If you exported the setup sheet too, the file is saved without the room layout page, and the message says the page was skipped.

Click the pop-out button in the editor's toolbar to bring the Layout window to the front, then export again.

Gear is grayed out in a picker

Every unit of that model is already on another row of this setup. The count shows it, for example 2/2 in use. That's the app stopping the same mic from being booked twice. To use it here:

  • Free one up by changing or clearing another row's cell.
  • If you're borrowing an extra one for this session, add it as Session Gear in Setup settings (⌘G). See Part 7.
  • If you own one, add it to Settings → Personal Gear Locker.

Counts are shared for a unit that appears in both the preamp and outboard lists, such as a channel strip. Using one in an Outboard cell also uses it up in the Preamp column.

A preset loaded with blank gear

When a channel preset names gear the studio doesn't have, the app leaves that cell blank and shows a Preset expected: badge with the name of the gear the preset wanted. Pick a replacement in that cell and the badge goes away. If you'd rather have the real thing, add it to the studio, to the setup's Session Gear, or to your Personal Gear Locker, then pick it. Part 7 covers presets.

The room layout page in the PDF is too small or too large

The layout page is sized from the file you uploaded:

  • Images (PNG, JPEG and so on) are fitted to a US Letter page: landscape for wide or square images, portrait for tall ones.
  • PDFs keep their own page size. A plan saved on a large architectural sheet prints that large; one saved on a small page prints small.

To fix it, save the floor plan again as a Letter-size PDF, or as an image so the app fits it for you. Then replace it: for the whole studio, use Replace Layout File in the studio editor; for one setup, use the Room Layout tab in Setup settings. Blocks, notes and markup stay where they are when the layout changes, so you may need to move a few.

A spreadsheet import skipped rows

The last step of Import from a spreadsheet… lists every skipped row with its reason:

  • no name: the row's name cell is empty.
  • looks like a totals row: the name reads like a total, so it isn't gear.
  • quantity is 0: there's a quantity column and this row's is zero.
  • no type or unknown type: you chose to read the kind of gear from a Type column, and this row's Type is empty or isn't one the app recognizes.

Title lines above the table are skipped on purpose. Click Back to change how the columns are matched, or fix the spreadsheet and import it again. Nothing is saved until you save the studio. Part 6 walks through the import.

Layout Mode asks for a room layout

The Room layout needed dialog appears when the setup doesn't have a floor plan yet. Choose Upload a Room Layout… to pick a file (PDF, PNG, JPEG, GIF, WebP, BMP or SVG), or Continue with a Blank Sheet to draw on plain white paper. After picking a file, choose Save to Studio to use it for every setup in the studio, or Just This Setup. You can change your choice later on the Room Layout tab in Setup settings. Part 4 has more.

Keyboard shortcuts don't work

Shortcuts are switched off while you're typing in a text box, so pressing a key types it rather than running a command. Click an empty part of the window to leave the box, then try again. If a shortcut still does nothing, check Settings → Keybinds: it may have been changed, or it may read Not set. The app's menus work either way.

There's no Faculty Reserve tab, or no Berklee folder

Berklee features are turned off. Turn on Settings → General → Berklee features. See Part 9.

Glossary

Setup
One session's plan: the setup sheet, its floor plan and its notes. Setups are listed under Saved Setups on the home screen.
Studio
A room and the gear in it: mics, outboard, preamps and a room layout. Every setup starts from a studio, and the gear pickers offer that studio's gear.
Studio template / gear list
A reusable starting point saved from a setup with Save as Studio… (⌘⇧S). It keeps the row list and column layout with the gear cleared, and appears as a Gear list card under New Setup From Studio Template.
Source
Anything you're recording on its own channel, such as Kick In or Lead Vocal. Each source is one row of the setup sheet.
Tie line
The numbered line that carries a signal from the live room to the control room. Two rows sharing one gets a warning.
Cue box
The headphone mix box a musician plugs into. The Cue box cell takes any text, such as 3 or 1-2.
Building office
A Berklee building's shared stock of gear, offered in every room in that building. See Part 9.
Faculty reserve
Berklee's faculty pool of mics, outboard and preamps, offered in a setup only when its faculty reserve switch is on. See Part 9.
Session gear
Gear borrowed for one setup only, added in Setup settings. It appears under This Session in that setup's pickers.
Personal gear locker
Your own gear, added in Settings → Personal Gear Locker. It's offered in every setup in every studio.
Quick setup
A setup with no studio behind it, for a one-off session. Its gear cells are plain text boxes that suggest names as you type.
Block
A shape on the floor plan standing for an instrument, amp, gobo or other item. Blocks come from the Layout Palette, or from + Add custom block.
Note
Text on the floor plan, either plain text or a yellow sticky note.
Markup
Freehand drawings on the floor plan: pen strokes, highlights, lines, arrows, ellipses and boxes. See Part 5.
Split View
Two setups open side by side in one window, each working on its own. See Part 7.
Pop-out window
The floor plan in its own window, for a second screen. Opened with the pop-out button in the editor's toolbar. See Part 7.
